# Інструкція щодо текстур (зображень)

Усі зображення підтримують формат **PNG з прозорим фоном**.

### 1. Фотографії шефа / власника:
- **Основне фото**: `assets/images/owner.png`
- **Додаткові / смішні фото (для 10% випадкових сюрпризів)**:
  - `assets/images/owner2.png` (наприклад: здивоване обличчя, сміх, лазерні очі, фото з клубом диму)
  - `assets/images/owner3.png`
- *Коли з вірогідністю 10% спрацьовує особлива подія, шеф може на 3.5 секунди змінити емоцію на `owner2.png`!*

### 2. Сопілкии / Одноразки / Рідини (`assets/images/vapes/`):
- `vape1.png`, `vape2.png`, `vape3.png`, `vape4.png`
- Квадратні або вертикальні PNG з прозорим фоном.

### 3. Текстура диму (`smoke.png`):
- `assets/images/smoke.png`
- Напівпрозора хмаринка пари для тіла змійки.
