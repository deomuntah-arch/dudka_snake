# 💨 Dudka Snake (Дудка Змійка)

Тематична веб-гра «Змійка» для творчого конкурсу сопілко-шопу.
Створена на чистому стеку: **HTML5, CSS3, Vanilla JavaScript** (без фреймворків і збирачів), що дозволяє миттєво розгорнути її на **GitHub Pages**.

---

## 🎮 Особливості гри

1. **Тематичні текстури**:
   - **Голова змійки**: Фотографія шефа/власника магазину ([assets/images/owner.png](file:///home/geerbeen/side_projects/dudka/assets/images/owner.png)) з динамічним поворотом за напрямком руху.
   - **Тіло змійки**: Клуби напівпрозорої пари/диму від сопілки ([assets/images/smoke.png](file:///home/geerbeen/side_projects/dudka/assets/images/smoke.png)), які залишаються за головою з ефектом розсіювання до хвоста.
   - **Їжа**: Різноманітні сопілкии, одноразки та баночки з рідиною ([assets/images/vapes/](file:///home/geerbeen/side_projects/dudka/assets/images/vapes/)).
2. **3 Рівні складності (розмір ігрового поля)**:
   - 🟢 **Мале поле**: `7 × 7` (49 клітинок) — повільна комфортна швидкість і швидка перемога!
   - 🔵 **Середнє поле**: `15 × 15` (225 клітинок) — класичний збалансований режим.
   - 🔴 **Велике поле**: `20 × 20` (400 клітинок) — режим справжнього дудка-гуру.
3. **Умови перемоги та програшу**:
   - **Перемога**: Досягається, коли змійка заповнює все ігрове поле! На екрані з'являється салют/конфеті, перемога супроводжується фанфарами.
   - **Програш**: Зіткнення зі стінами поля або власним хвостом.
4. **Керування для ПК та Смартфонів**:
   - 💻 **ПК**: Клавіші стрілок `↑ ↓ ← →` або `W, A, S, D`, пробіл для паузи, `R` для рестарту.
   - 📱 **Мобільні пристрої**:
     - Сенсорні свайпи пальцем по ігровому полю (з блокуванням випадкового скролу сторінки).
     - Віртуальний D-Pad (кнопки керування внизу екрана), який автоматично з'являється на сенсорних пристроях.
5. **Аудіосистема**:
   - Звуковий ефект **"Чпок"** при підбиранні сопілки.
   - Звуки аварії при програші та урочисті **фанфари** при перемозі (Web Audio API — нульова затримка).
   - **Випадковий вибір треку**: при кожному старті гри автоматично вмикається випадковий трек з папки `assets/audio/music/` (без повторів).

## ⚙️ Як самостійно швидко змінювати розмір поля та швидкість

У самому верху файлу [js/game.js](file:///home/geerbeen/side_projects/dudka/js/game.js#L7-L28) є блок `GAME_CONFIG`:

```javascript
const GAME_CONFIG = {
  difficulties: {
    easy: {
      gridSize: 7,      // Розмір поля (7x7) — змінюйте на будь-яке число!
      speed: 240,       // Затримка у мс (БІЛЬШЕ число = ПОВІЛЬНІША змійка)
      label: '7 × 7'
    },
    ...
  }
};
```
- Змініть `gridSize` на будь-який потрібний розмір (наприклад `5`, `6`, `8`).
- Змініть `speed` (наприклад, `300` для дуже повільної, `200` для трохи швидшої).

## 🎵 Як додати власну музику

1. Покладіть аудіофайли (`.mp3` або `.wav`) у папку [assets/audio/music/](file:///home/geerbeen/side_projects/dudka/assets/audio/music/).
2. Додайте назву файлу у [assets/audio/music/playlist.json](file:///home/geerbeen/side_projects/dudka/assets/audio/music/playlist.json):
   ```json
   [
     "chill_vape_beat.wav",
     "track1.mp3"
   ]
   ```
   *(Або якщо назвете файл просто `track1.mp3`, `track2.mp3` — гра сама знайде його автоматично!)*
3. При старті кожної гри обиратиметься **випадковий трек**.
